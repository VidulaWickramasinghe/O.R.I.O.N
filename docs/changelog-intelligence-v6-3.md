# O.R.I.O.N. v6.3 — Changelog Intelligence + Release Notes Composer

v6.3 composes local changelog entries, release-note drafts, public update
summaries, and maintenance communication packs from patch workflow data.

Artifacts are written only to `backend/data/changelog_intelligence/`. The
composer never publishes notes, pushes to GitHub, modifies GitHub releases or
issues, deletes files, exposes secrets, or bypasses approvals.
