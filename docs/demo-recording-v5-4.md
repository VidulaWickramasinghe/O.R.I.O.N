# O.R.I.O.N. v5.4 — Demo Recording Mode + Presenter Controls

## Overview
v5.4 adds presentation controls for recording clean O.R.I.O.N. demo videos.

## Features
- Presenter controls, scene presets, large callout, timer, checklist, and clean layout mode.
- Recording readiness report, API endpoints, tools, and scanner checks.

## Safety
Recording Mode is presentation-only. It does not start screen recording automatically, publish, execute tools, or bypass approvals.
