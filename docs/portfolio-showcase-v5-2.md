# O.R.I.O.N. v5.2 — Screenshot Gallery + Portfolio Case Study Page

v5.2 adds presentation-only Aurora OS portfolio assets: a screenshot registry and gallery, case study, public demo narrative, and local screenshot-readiness reporting.

## API

- `GET /api/portfolio-showcase/status`
- `POST /api/portfolio-showcase/report/save`

Screenshots can be placed in `assets/screenshots/` and copied to `frontend/public/screenshots/` for gallery presentation.

## Safety

This phase does not push, publish, delete, expose secrets, or bypass approvals.
