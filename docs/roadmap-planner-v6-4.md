# O.R.I.O.N. v6.4 — Roadmap Planner + Future Feature Governance

v6.4 adds a local future-feature registry, classification, priority scoring,
safety review, release bucket planning, governance checks, and roadmap package
generation.

Generated data remains under `backend/data/roadmap_planner/`. The planner does
not implement features, modify GitHub issues, push code, publish releases,
delete files, expose secrets, or bypass approvals.
